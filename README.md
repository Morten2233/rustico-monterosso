# Rustico Soviore – Verkaufsseite

Statische Seite (DE/EN/IT) für das Rustico oberhalb von Monterosso al Mare.

- Texte und Bildunterschriften: `_build/content.json`
- Seiten neu erzeugen: `python _build/build.py` (schreibt `index.html`, `en/`, `it/`)
- Anfrageformular: sendet per FormSubmit an die in `form_endpoint` hinterlegte Adresse.
